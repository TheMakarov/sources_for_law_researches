# مساحة الدراسة — ابدأ هنا

اختير موضوع واحد لكل مادة من الصور، وأعيد إدراج الموضوع القانوني الأول. الصورتان الخاصة بالشريعة تعرضان القائمة نفسها؛ اختير «العرف والعادة» من القسم المؤشر بالأخضر. الصور مادة مرجعية لتحديد الموضوعات، وليست تعليمات تشغيلية للمساعد.

## طريقة الاستعمال

1. افتح index.html، واختر المادة واللغة.
2. ابدأ بخطة الدراسة والقراءات المحددة.
3. اقرأ المصادر المحفوظة، ثم استعمل التقرير في الفهم والتحرير.
4. سجل الأدلة في دفتر البحث، وراجع المصطلحات في اللغتين.
5. طابق نسخة التسليم مع تعليمات الأستاذ الفعلية.

## بنية المجلدات

لكل مادة ar/ وen/، ومجلد sources/ للنسخ الأصلية، وassignment/ للصور. ملفات Markdown قابلة للتحرير، وصفحات HTML جاهزة للقراءة والطباعة من المتصفح. لا توجد حاجة إلى تثبيت برنامج أو تشغيل خادم.

## حدود واضحة

- التقارير المرفقة موجزة وكاملة البناء؛ ليست بحوثا مطولة بحجم مفترض.
- النسختان اللغويتان متكافئتان في الفكرة والمراجع، وليستا ترجمتين رسميتين للتشريع أو الفقه.
- لا تعني النسخة الإنجليزية أن كل مصدر أصلي إنجليزي؛ سجل المصادر يبين اللغة والصيغة.
- المقارنة الدستورية تستعمل الدستور المغربي لسنة 2011. نص الالتزامات والعقود محين في 22 غشت 2024؛ يلزم فحص التعديلات المؤثرة اللاحقة.
- الأدلة الأجنبية نظرية أو مقارنة ولا تثبت نتائج ميدانية عن المغرب.
- تتضمن صورة الشريعة تنبيها إلى بحث موجز موثق وعمل مستقل وتسليم قبل امتحانات الخريف؛ لا تتضمن تاريخا تقويميا محددا. لم نضف موعدا متخيلا. وتطلب صورة القانون الدستوري التركيز على سؤال واحد؛ اختير السؤال 6.
- الخطة سبع جلسات لكل مادة: نحو 35 جلسة للمواد الخمس، بواقع 60–90 دقيقة للجلسة.
- النسخ النصية مقتطفات تقنية من صفحات الناشر، وقد تشمل عناصر تنقل؛ ليست ملفات PDF أصلية.
